Release notes

What changed in each version of werkz, newest first. Downloads are on the releases page.

  1. v0.1.11Latest2026-11-28

    Fixed

    • Reply and tool bullets are ● outside macOS and in Ghostty, where ⏺ was drawn as a colour emoji
    Downloads for v0.1.11
  2. v0.1.102026-11-28

    New

    • Claude Code drives werkz's browser: werkz lends it the browser, DevServer and MCP tools and runs them itself
    • OpenCode Zen provider: one key for OpenCode's hosted models, with their prices in /model (closes #2)
    • Live browser view in every terminal: opens above the input while the model browses, frames only when the page changes, marked clicks and typing; kitty, iTerm2, Sixel, half-block text and tmux passthrough
    • Switching from Claude Code to an API model keeps what Claude Code's tools read, ran and found; fix: polled live frames sized to the window with marks in place, the Windows connect command runs in PowerShell
    • /browser connect uses the Chrome you already have open

    Fixed

    • Show the provider's reason when a model isn't found; Gemini defaults to gemini-flash-latest (2.5 Flash is retired for new users)
    • Retry a page load when Chrome's certificate checker or network changes mid-load
    • Show what a page does on its own between actions as it happens, and tell the model with its next request (closes #1)
    • Sixel full view keeps moving on a page that keeps changing (draws the newest finished frame, one encode at a time) and fits xterm's 1000-pixel limit
    • Closing the live strip no longer leaves a band of the last frame in Sixel and iTerm2 terminals; WezTerm and foot tested
    Downloads for v0.1.10
  3. v0.1.92026-11-26

    New

    • See werkz's browser inside your terminal
    • Connect werkz to your own Chrome, and drive pages with mouse and keyboard
    • Use tools from MCP servers

    Fixed

    • Harden web access and werkz's browser after review
    • Copying works on Linux desktops without a clipboard tool
    • Close the gaps found in review (plan mode, downloads, approvals, MCP approval, untrusted text, signals)
    • History moves, downloads in your own Chrome's tabs, MCP approval dialog and wording, after re-review
    • Block downloads while werkz opens pages in your own Chrome; show hidden characters in MCP approvals
    • Say when a page started a download after werkz's action finished; watching the live view leaves your downloads alone
    Downloads for v0.1.9
  4. v0.1.82026-11-26

    New

    • WebFetch and WebSearch let the model read pages and search the web
    • Werkz checks its own web UI in your installed Chrome
    Downloads for v0.1.8
  5. v0.1.72026-11-26

    New

    • @file mentions, drag-to-copy, and /resume to continue saved conversations
    Downloads for v0.1.7
  6. v0.1.62026-11-26

    New

    • Choose your own context window (/context window 350k)
    • Say when an update is available and how to get it for each install method
    • Show subscription usage limits (/usage, status bar, warnings)
    • New website with docs, install methods and release notes
    • Bypass permissions mode (confirmed, never saved), and edit previews that show only what changes
    • Professional redesign in the logo's colours, light and dark themes, real product shot, contributing guide
    • Typewriter effect on the hero headline
    • 90s typewriter headline (Special Elite) with struck, inked letters and a block cursor
    • Live werkz session replayed in the hero window

    Fixed

    • Sign in over SSH, without a desktop, and on WSL

    Packaging

    • Goldmark is a direct dependency (used by the site generator)
    Downloads for v0.1.6
  7. v0.1.52026-11-26

    Fixed

    • Find Claude Code outside PATH, and make subscriptions easy to find
    Downloads for v0.1.5
  8. v0.1.42026-11-26

    New

    • Sign in with ChatGPT and a Responses API client for plan usage
    • Run the installed Claude Code as a backend, with werkz answering its permission prompts
    • Use a ChatGPT plan or Claude subscription alongside API keys

    Fixed

    • Rebuild the icon cache on uninstall
    Downloads for v0.1.4
  9. v0.1.32026-11-25

    Downloads for v0.1.3

    • Release with GoReleaser (binaries, deb/rpm/apk/arch packages, Homebrew cask)
    Downloads for v0.1.2
  11. v0.1.12026-11-25

    New

    • Self-update from GitHub releases
    • Update werkz automatically, plus /update and werkz --update
    Downloads for v0.1.1
  12. v0.1.02026-11-25

    New

    • Settings, provider registry, workspaces and fallback chain
    • Model catalog, pricing and prompt-cache cost math
    • Provider-neutral messages, tool calls and Provider interface
    • File, search and shell tools with read-before-edit guard, output trimming and spill files
    • Anthropic backend with streaming, adaptive thinking, effort, fast mode and prompt caching
    • OpenAI-compatible backend for OpenAI, Grok, Gemini, OpenRouter (free and paid), Groq and Ollama
    • Agent loop with permissions, provider fallback, compaction, Task sub-agent and cache keep-alive
    • Full-screen terminal UI with streaming transcript, dialogs, workspaces and status bar
    • Werkz command entry point
    • Try free providers first in the default fallback order
    • Reuse provider clients; always close Claude streams
    • Report the module version for go install builds
    • One-line installer that downloads and verifies a GitHub release

    Fixed

    • Never switch providers when the main one is disabled and fallback is off
    • Run the Task sub-agent on the user's current provider
    • Stop typeahead from answering permission and fallback dialogs
    • Kill whole process groups on timeout and cancel; cap Bash output
    • Resolve symlinks when checking writes against the working folders
    • Ask before reading outside the working folders; never open credential files; home is not a project
    • Start every session in the default permission mode
    • Scope Bash "don't ask again" to a command prefix
    • Remove the keep-alive data race
    • Compact before adding the new message so it is never summarised away
    • Never overwrite a broken config file; save atomically with 0600
    • Use real prices and provider-reported cost; flag unknown prices
    • Label Gemini and Groq as free tiers, not free
    • Stay on the fallback model for the rest of the turn
    • Keep index-less tool calls separate; treat cut-off streams as errors
    • Replace withdrawn free models automatically
    • Strip terminal escape sequences from model, tool and provider text
    • Make Grep and Glob stop when the turn is cancelled
    • Accurate "more lines follow" hint in Read; report unreadable lines
    • Add --provider, recognise OpenAI o-series models, don't save --model
    • Accept OLLAMA_HOST without a scheme
    • Send project instruction files once, as repository context
    • Stop the cache keep-alive when switching model, effort or fast mode
    • Re-enable a provider once /login confirms its key works
    • Tell the user when tools are dropped; remember rejected options; add timeouts
    • Quote paths safely in launchers and the .desktop entry
    • Don't store empty replies; let /compact recover from context overflow

    Packaging

    • Linux and macOS packaging with launchers, installer and app icon
    • Build with Go 1.26.11 and update x/net, x/text and goldmark
    • Produce release assets with bare binaries and SHA256SUMS
    Downloads for v0.1.0
