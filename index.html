Install werkz

werkz is an agentic coding tool for the terminal. Pick one way to install it.

One-line installer (Linux and macOS)

curl -fsSL https://raw.githubusercontent.com/TonmoyTalukder/werkz/main/install.sh | sh

Installs the latest release for Linux (x86-64, ARM64) or macOS (Apple Silicon, Intel), with an app icon. werkz then updates itself.

Homebrew (macOS and Linux)

brew install --cask ZenixBit/tap/werkz

Installs the werkz command. Update with brew upgrade --cask werkz.

Debian, Ubuntu (apt)

sudo install -d -m 755 /etc/apt/keyrings
curl -fsSL https://tonmoytalukder.github.io/werkz/werkz.gpg | sudo tee /etc/apt/keyrings/werkz.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/werkz.gpg] https://tonmoytalukder.github.io/werkz/apt stable main" | sudo tee /etc/apt/sources.list.d/werkz.list
sudo apt update
sudo apt install werkz

Fedora, RHEL (dnf)

sudo curl -fsSL https://tonmoytalukder.github.io/werkz/rpm/werkz.repo -o /etc/yum.repos.d/werkz.repo
sudo dnf install werkz

Updates arrive with sudo apt upgrade or sudo dnf upgrade. The apt and dnf packages and repositories are signed with the key werkz.asc (fingerprint 3148 F0F0 B5B3 55FC 9FC1 9B2C 20A3 4C2D 3430 3C54). Other ways to install: installation guide.
